# Levantamento

Material de campo (da organização atendida, das entrevistas, dos sistemas consultados), em retratos datados: um arquivo por fonte, com o nome
`AAAA-MM-DD-fonte.md` (por exemplo, `2026-10-03-crm.md`). Cada arquivo abre com a data, a fonte e quem
autorizou o acesso.

Sistemas mudam e acessos caem; o retrato datado continua valendo como fonte do texto. Dado pessoal de
cliente ou de colega não entra aqui: registre o fato, sem o dado.
