# ESAG

Pasta dos trabalhos do João na ESAG/UDESC. Cada subpasta é um trabalho, e o TCC mora em `tcc/`.
O TCC relata o trabalho do João na Getdemo, então os repos em `~/getdemo` e as fontes da Getdemo
(HubSpot, warehouse, Drive, Slack) são material de leitura. Os arquivos dos trabalhos moram só aqui.

Desde 05/10/2026, o `tcc/` é um repo git com cópia no GitHub; como operar está no `tcc/CLAUDE.md`, seção
"Git". As outras pastas não têm git e existem só neste disco, no container `getdemo-dev`.

TCC: antes de qualquer trabalho nele, leia `tcc/CLAUDE.md` e siga a seção "Início de toda sessão".

A formatação ABNT da ESAG está na skill global `tcc-esag`, que gera o HTML e o PDF.
